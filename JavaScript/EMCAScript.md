**What ECMASCript**

JavaScript is just a programming language conforms to the ECMAScript standard. ES6 release summer 2015. Many features writing Javascript easier and cleaner. 

Release schedule
- ES6 is ES2015, ES7, ES2016

**Browser support**

- JavaScript constantly updating adding features, take web browsers little while to catch up.
- takes a couple years for widely available. This means write code using brand new features, **will not run** in certain browsers

**Babel**

- tool takes your modern, *transpiles* it to code older broswers can understand. Transpile to any number of targets. 
- Not something you will need to worry about a lot
